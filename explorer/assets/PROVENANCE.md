# Source icon provenance

`blob.svg`, `search.svg`, `web.svg`, and `source.svg` are original neutral line
drawings authored for this companion application and distributed under its MIT
license. They are not Microsoft product logos or official Azure architecture
icons. No third-party artwork, font, CDN, or remote image is loaded.

The local registry supplies text labels (Blob / Search index / Web and Indexed /
Remote). Images are decorative; labels remain available to assistive technology.
Unrecognized source kinds use the neutral document fallback. Official source
assets must not replace these placeholders until their redistribution terms and
specific asset approval have been recorded.
